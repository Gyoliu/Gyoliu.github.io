场景对比

推荐等级 项目 核心定位 最适合场景 优点 缺点 / 注意点 许可证
首选 Prometheus + Grafana 现代指标监控 + 可视化黄金组合 云原生、Kubernetes、容器、微服务、动态环境 生态最强（Exporter 海量）、PromQL 强大、可扩展性极好、社区活跃 需自己组装（Prometheus 采集 + Grafana 展示 + Alertmanager 告警），初期配置有学习成本 Apache 2.0 / AGPL
企业级一体机 Zabbix 全功能企业级监控平台 传统服务器 + 网络设备 + 混合环境、大规模主机 开箱即用（Agent/Agentless/SNMP/IPMI/JMX）、模板丰富、自动发现、告警完善、可扩展到万级主机 对 K8s/微服务支持相对较弱，UI 相对传统 AGPL/GPL
实时轻量 Netdata 零配置实时性能监控 单机或小规模服务器、故障排查、实时查看 安装极快（分钟级）、秒级粒度、自动发现服务、内置漂亮 UI、资源占用可控 大规模集中监控需配合其他工具，默认更侧重单机深度 GPL-3.0
轻量新星 Beszel 超轻量服务器监控 1–20 台服务器、家用/小型环境 资源占用极低（Agent 约 10–15 MB）、部署简单、界面清爽 功能相对聚焦，不如 Prometheus/Zabbix 全面 MIT
可用性/状态页 Uptime Kuma 服务可用性 + 状态页 监控网站/API 是否存活、对外状态页 单容器部署、支持多种协议、通知渠道极多、界面友好 主要做可用性，不做深度系统指标 MIT

数据存储 01-storage.yaml ，使用 Local File SQLite

apiVersion: v1
kind: Namespace
metadata:
  name: beszel
---
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: beszel-local
provisioner: kubernetes.io/no-provisioner
volumeBindingMode: WaitForFirstConsumer
reclaimPolicy: Retain
---
apiVersion: v1
kind: PersistentVolume
metadata:
  name: beszel-local-pv
spec:
  capacity:
    storage: 30Gi
  volumeMode: Filesystem
  accessModes:
    - ReadWriteOnce
  persistentVolumeReclaimPolicy: Retain
  storageClassName: beszel-local
  local:
  // 数据存储目录
    path: /data/beszel
  nodeAffinity:
    required:
      nodeSelectorTerms:
        - matchExpressions:
            - key: kubernetes.io/hostname
              operator: In
              values:
              // 指定了k8s服务器
                - centos-k8s-server2
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: beszel-data
  namespace: beszel
spec:
  accessModes:
    - ReadWriteOnce
  storageClassName: beszel-local
  resources:
    requests:
      storage: 30Gi

服务端部署 02-beszel.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: beszel
  namespace: beszel
spec:
  replicas: 1
  strategy:
    type: Recreate
  selector:
    matchLabels:
      app: beszel
  template:
    metadata:
      labels:
        app: beszel
    spec:
      terminationGracePeriodSeconds: 30
      containers:
        - name: beszel
          image: henrygd/beszel:0.20.0
          imagePullPolicy: IfNotPresent
          env:
            - name: APP_URL
              value: "https://monitor.com"
            - name: CHECK_UPDATES
              value: "false"
            - name: SHARE_ALL_SYSTEMS
              value: "false"
            - name: USER_CREATION
              value: "false"
            - name: MFA_OTP
              value: "true"
          ports:
            - name: http
              // 将端口暴露到宿主机器上
              hostPort: 8090
              containerPort: 8090
              protocol: TCP
          volumeMounts:
            - name: beszel-data
              mountPath: /beszel_data
          resources:
            requests:
              cpu: 50m
              memory: 128Mi
            limits:
              cpu: "1"
              memory: 512Mi
          readinessProbe:
            exec:
              command:
                - /beszel
                - health
                - --url
                - http://127.0.0.1:8090
            initialDelaySeconds: 10
            periodSeconds: 20
            timeoutSeconds: 5
            failureThreshold: 3
          livenessProbe:
            exec:
              command:
                - /beszel
                - health
                - --url
                - http://127.0.0.1:8090
            initialDelaySeconds: 30
            periodSeconds: 60
            timeoutSeconds: 5
            failureThreshold: 3
      volumes:
        - name: beszel-data
          persistentVolumeClaim:
            claimName: beszel-data
---
apiVersion: v1
kind: Service
metadata:
  name: beszel
  namespace: beszel
spec:
  type: ClusterIP
  selector:
    app: beszel
  ports:
    - name: http
      protocol: TCP
      port: 8090
      targetPort: 8090

Nginx 代理访问

server {
    listen 443 ssl http2;
    server_name monitor.com;

    ssl_certificate     /etc/nginx/ssl/monitor/fullchain.pem;
    ssl_certificate_key /etc/nginx/ssl/monitor/privkey.pem;

    location / {
        proxy_pass http://<BESZEL_NODE_IP>:8090;

        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_connect_timeout 10s;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }
}

服务器Agent安装

# 固定版本 -v '0.20.0'
# 禁用更新 --auto-update false
curl -sL https://get.beszel.dev -o /tmp/install-agent.sh \
&& chmod +x /tmp/install-agent.sh \
&& /tmp/install-agent.sh \
  -p 45876 \
  -k "YOUR_KEY" \
  -t "YOUR_TOKEN" \
  -url "https://monitor.com" \
  -v '0.20.0' \
  --china-mirrors \
  --auto-update false

sudo vi /etc/systemd/system/beszel-agent.service
2.增加
> Environment="EXTRA_FILESYSTEMS=/data,/opt/elasticsearch"

sudo systemctl daemon-reload
sudo systemctl status beszel-agent
sudo systemctl restart beszel-agent
journalctl -u beszel-agent -n 100 --no-pager
