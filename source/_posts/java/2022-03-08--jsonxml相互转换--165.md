### 案例
```java
// xml 转换为 json
XMLSerializer xmlSerializer = new XMLSerializer();
JSON read = xmlSerializer.read(xml);
System.out.println(read.toString());

// json 转换为 xml
String write = xmlSerializer.write(read);
System.out.println(write);
```
